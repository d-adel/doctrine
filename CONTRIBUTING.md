# Contributing

## Issues

Bug reports and proposals are welcome as issues. For a process failure, describe what the plugin
let through or refused, the command that ran, and what you expected; a general cause is repaired
here, a project's specifics belong in that project's `doctrine/profile.md`.

## Pull requests

Open an issue first for anything beyond a small fix, so the change is agreed before it is written.
Keep a pull request to one change.

## Tests

    python -m unittest discover -s tests

The tests use the standard library only and must pass.
